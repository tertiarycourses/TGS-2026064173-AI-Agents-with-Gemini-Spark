# Approval map

| Action class | Example | Default | Evidence required |
|---|---|---|---|
| Observe | Read approved public sources | May continue | Source log |
| Draft | Create a local content draft | May continue | Draft filename and diff |
| Modify | Edit local project files | Review each patch | Git diff and tests |
| Communicate | Send email or form | Human executes | Approved final text |
| Publish | Deploy website | Human approves | Test report and rollback commit |
| Transact | Purchase or payment | Human takes over | Explicit transaction approval |
